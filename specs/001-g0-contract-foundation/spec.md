# G0 contract foundation specification

Converge dependency group G0 from the authoritative v6.0 PRD without modifying normative docs. The milestone establishes
canonical product truth, bounded first-party observation, exact Tool Core behavior, permanent read-only security, and an
integrated API/MCP/persistence walking skeleton. Unsupported providers/programs remain explicit. All time-dependent facts
retain event time, receipt time, earliest availability, revision, quality, provenance, and evidence lineage.

Success is measured by the acceptance criteria and requirement IDs in `../factory/current-milestone.json`, PRD drift
verification, focused unit/integration/system tests, architecture boundaries, and conformance evidence.
