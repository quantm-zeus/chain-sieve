# Rolling milestone roadmap

1. **G0 contract foundation** — canonical truth, observation boundary, Tool Core, MCP/security perimeter, integrated
   evidence. This is the only decomposed milestone.
2. **G1 deterministic signal and execution baseline** — snapshots/features, pool adapters, candidate funnel, evaluation.
3. **G2 durable operations** — workflow, scheduler, alerts, recovery, admin observability.
4. **G3 model-assisted research** — bounded agent runtime, evidence planner, Workbench.
5. **G4–G5 intelligence depth** — timing/thesis/regime, wallet/deployer/liquidity/narrative modules under capability gates.
6. **G6 distribution readiness** — public compatibility, claims/rights/security release controls.
7. **G7 adaptive allocation and Alpha Lab** — exploration, adversarial validation, governance, bounded offline imports.
8. **Final product audit/remediation** — independent structured Codex audit; DONE only when docs, implementation, tests,
   and runtime evidence converge.

Each next milestone is decomposed into two to eight outcome packages only after the current milestone converges.
