# ChainSieve spec-driven constitution

The authoritative product PRD and its normative manifests are immutable product authority. Spec Kit artifacts refine,
map, plan, analyze, and converge against that authority; they never replace it. Planning uses rolling milestones with two
to eight stable-ID outcome packages. Ordinary ambiguity is resolved autonomously and material choices are recorded as
ADRs. `/speckit.implement` is excluded from the production factory loop because Agent Orchestrator owns execution.
`/speckit.converge` is used after integration to append idempotent remediation packages when implementation still drifts
from spec, plan, tasks, tests, or runtime evidence.

All planning, worker, review, convergence, and final-audit roles inherit `factory/constitution.md`.
