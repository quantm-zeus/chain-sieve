# Security policy

This repository is permanently read-only regarding financial activity. Do not add transaction construction, signing, submission, custody, wallet-secret handling, swaps, approvals, bridging, staking, or exchange orders. Report vulnerabilities privately to the repository owner. Do not include credentials, provider payloads containing personal data, or exploitable details in public issues. MCP origins, protocol version, content type, authentication, session scope, and tool allowlists fail closed before tool execution.
